# RMStudio releases

Release downloads for **RMStudio**, a Blender 5.2 add-on for animating mixed-rig avatars.

## Install
1. Download `rmstudio-<version>.zip` from the latest [release](https://github.com/DrMitchel/rmstudio-releases/releases/latest).
2. In Blender: **Edit > Preferences > Get Extensions > (menu top right) > Install from Disk** and pick the zip.

## Updates
RMStudio checks this page once a day (when Blender's *Allow Online Access* is on) and shows
**Update available** at the top of its panel. One click downloads and installs the new version.
You can switch the daily check off in the add-on's preferences.

The source code is private; this repository only holds the release files.
